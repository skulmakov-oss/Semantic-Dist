# Contributing to Semantic-Dist

We welcome contributions to packaging scripts, launcher integrations, and documentation for `Semantic-Dist`.

## Contribution Rules

1. All contributions must target an issue and proceed via pull request.
2. PRs must pass all CI checks, including provenance verification and smoke testing.
3. PRs require review and explicit repository owner approval (`OWNER MERGE GO`) before landing.
4. No changes to upstream compiler sources or language contracts may be proposed here; report compiler bugs to `skulmakov-oss/Semantic`.
